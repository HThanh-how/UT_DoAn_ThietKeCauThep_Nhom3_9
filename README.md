# Trình chiếu đồ án thiết kế cầu thép

Deck gồm 12 slide, giữ nguyên logic điều khiển từ deck tham chiếu và chỉ thay nội dung sang đồ án cầu thép.

## Trình chiếu

Mở PowerShell tại thư mục này rồi chạy:

```powershell
npm run present
```

Mở địa chỉ mà lệnh hiển thị (thường là `http://localhost:3000`) và bấm **Play** hoặc phím `P`.
Di chuyển bằng phím mũi tên. Các công cụ gốc của deck mẫu vẫn giữ nguyên: chuột laser (`L`), bút vẽ (`D`), màn hình đen (`B`), chọn slide (`G`), danh sách chương và menu chuột phải. Deck không có audio hay lời thuyết minh.

## Nội dung

- Cơ sở thiết kế, sơ đồ và bố trí 6 dầm chủ.
- Bản mặt cầu, tiết diện dầm I, đường ảnh hưởng và nội lực khống chế.
- Sườn tăng cường, liên kết ngang, mối nối và bảng kiểm toán.
